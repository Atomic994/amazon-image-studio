# 本地素材工作流调试

素材、商品事实和参考图分析均使用浏览器本地存储，不需要新增后端，继续兼容 Cloudflare Workers 静态部署。本说明适用于本地调试，也可以用于部署后的功能检查。

## 参考复用、最终稿和主题预设检查

1. 在参考图卡片展开适用范围，同时勾选两个图片位；存入图库后，确认这两个范围仍在。选用时展开“此次加入时统一设置用途和范围”，换成其他两个图片位后加入：当前策划应采用新范围，图库原条目应保留原范围。生成结果也可直接存入图库，默认用途应为构图排版，来源图片位和参考范围应正确。
2. 打开“整套最终稿总览”：生成前应列出缺少的图片位；生成后显示各自的候选结果和实际尺寸。逐项选稿、填写不同审核意见；未全部确认时完整交付按钮不可用，可仅导出确认项，清单应列出缺项。全部确认后导出 ZIP，应逐图片位保留文件和各自意见。保存为套组并刷新、恢复副本后，确认稿仍应可查看。不同图片位即使返回相同图片内容，也应分别保留和审核。
3. 打开“主题 / 场景预设”，载入内置主题并改名保存。刷新后应能再次找到；应用到另一个商品时，只带入场景、布局、光线、限制和信息密度。附图与 A+ 的实际提示词应带有新要求，MAIN 不带场景预设。改变主题后，已有附图最终稿应提示复核，MAIN 不应仅因此失效。
4. 从素材库备份本地数据，换浏览器或域名时通过设置导入任务数据；核对主题预设、图库来源、多图片位范围和最终稿确认记录都恢复，队列保持暂停。升级期间如出现数据库被旧标签页占用的提示，关闭同一网站的其他旧标签页后刷新。

## 打开与配置

本地预览地址：`http://127.0.0.1:5179/`。该地址使用生产构建。可在项目目录运行：

```powershell
npm run build
npm run preview -- --host 127.0.0.1 --port 5179 --strictPort
```

首次在该地址打开时，在“设置 → API”填写自己的生图和策划配置。浏览器按网站地址隔离数据，线上网站、不同本地端口和不同浏览器之间不会自动共享 API 配置或历史记录。

## 建议检查顺序

1. **结果对比和版本记录**：生成一张 MAIN，再编辑一次；在任务卡片或编辑结果点击“对比 / 版本”。左右选择版本，调整同步缩放，填写意见并“通过并设为最终稿”。修改意见后点“保存意见”会保留最终稿状态。返回历史列表可看到最终稿标记。
2. **参考图用途**：上传商品图和一张构图参考。将构图图设置为“构图排版 / 仅 PT01”。生成 MAIN 时只采用适用于 MAIN 的图片；生成 PT01 时采用商品图、构图图，以及所选的隐藏风格图。用途和说明会随历史、套组保留。
3. **单模块策划**：选中 PT01 或某个 A+ 模块，在 Prompt Preview 旁点击“单图策划 / 版本”。填写要求后，只重策划这一项。可展开日志查看请求、接收和校验阶段；成功会保存 v2，失败可重试，停止不会保存半成品。选择 v1 后可恢复，v2 仍保留。
4. **成套收藏**：点击“收藏整套素材”，选择要保存的图片；同一图片位默认优先选最终稿或最新结果。也可以多选历史记录后点击“存为套组”。从顶部“素材库”查看、下载、复用配置，或恢复整套策划为新副本。保存到已有套组时，会带上未替换的原套组图片，可自行调整选择。
5. **刷新与备份**：刷新后重新打开素材库，检查套组和版本；恢复整套策划后检查参考图用途、模块版本仍在。普通历史记录删除时，套组引用的图片会继续保留。可在“素材库 → 备份本地数据”导出 ZIP，再通过“设置 → 数据管理”导入任务数据。
6. **商品事实确认**：展开参考图下的“查看 / 编辑商品事实与版本”，点击“AI 提取事实草稿”并展开日志。检查只使用商品实物图，不把构图或风格图当作商品事实。修改实际颜色、包装清单等信息，再点“确认并保存新版本”；Prompt Preview 应显示事实版本。未核实的材质、尺寸和认证保留未知。再次修改并确认后，旧方案提示需要复核；单图重策划将保存新的上下文。恢复旧事实版本不会删除新版本。生成后进入图片编辑，应显示“保持来源商品事实”的勾选项。
7. **参考图分析**：点击任意“分析参考图”，优先缓存分析；关闭后再次点击“复用缓存 / 检查分析”，日志应显示无需请求 LLM。改变用途、范围、说明或策划模型后，原分析不再显示为有效匹配。点击“强制重新分析”会请求新结果；失败、停止不覆盖完整旧记录。刷新、恢复历史或套组后，应仍能查看保存在版本中的分析快照。正式生成始终附带对应参考原图。
8. **单套 ZIP**：素材库中选中某个套组和历史版本，点“导出本套 ZIP”；解压后应只有此版本的 `images/`、`manifest.json` 和说明文件。核对文件名中的图片位和套组版本、原图实际像素及事实快照，不应出现其他套组图片或 API 配置。若所选版本没有生成图片，导出按钮不可用。

## 数据范围

- 素材库的备份按钮只导出任务数据，包含图片、参考图、策划与套组版本、审核意见及最终稿选择，不导出 API 配置。
- 模型提示词、参数和参考用途可以复用；复用操作先填入配置，不会自动发起收费生成。
- 原有的逐图独立编辑、回首页保留策划、翻译缓存与日志继续保留。
- 参考图临时分析缓存按 30 天未使用清理，每次实际复用续期；只查看缓存状态不续期。策划历史、生成任务和素材版本里的事实与分析快照不受缓存期限影响，会随完整数据备份迁移。
- 单套 ZIP 用于交付生成图片和说明，不包含参考原图或完整项目数据，不作为数据恢复导入包。
- 清除浏览器网站数据或在设置中清空全部任务数据，会删除本地素材；迁移前请先备份。
- 本轮没有增加服装批量套图、登录、多账号或服务端存储。
